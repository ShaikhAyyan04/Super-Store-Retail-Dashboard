# 📊 Sales & Profit Dashboard – Excel

## 📌 Project Overview

This project is an **interactive Sales & Profit Dashboard developed using Microsoft Excel**.

The dashboard is designed to analyze **sales, profit, profit margin, product categories, and regional performance**. It uses advanced Excel and Business Intelligence features such as **Power Query, Power Pivot, DAX, Pivot Charts, Charts, Slicers, and Filters**.

The dashboard helps convert raw sales data into meaningful business insights through interactive visualizations and KPIs.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze total sales and total profit.
- Calculate and monitor profit margin.
- Compare sales and profit across product categories.
- Analyze regional sales performance.
- Identify high-performing and low-performing categories.
- Create an interactive dashboard for business analysis.
- Use Power Query for data cleaning and transformation.
- Use Power Pivot for data modeling.
- Use DAX for creating calculated measures.
- Present insights through charts, Pivot Charts, Slicers, and Filters.

---

# 💼 Business Problem

Businesses generate large amounts of sales data, but raw data alone does not provide an easy understanding of business performance.

The objective of this dashboard is to provide a simple solution for analyzing:

- **Sales Performance**
- **Profit Performance**
- **Profit Margin**
- **Category Performance**
- **Regional Performance**

The dashboard allows users to interact with the data and quickly understand how different categories and regions contribute to overall business performance.

---

# ❓ Business Questions

The dashboard is designed to answer the following questions:

1. What is the total sales generated?
2. What is the total profit generated?
3. What is the overall profit margin?
4. Which product category generates the highest sales?
5. Which category generates the highest profit?
6. Which category has the highest profit margin?
7. How does profit margin vary across categories?
8. How does sales performance change by region?
9. Which region contributes the most to sales?
10. Which region contributes the most to profit?
11. Which categories require attention because of lower profit margins?
12. How does regional filtering affect category performance?
13. What is the relationship between sales and profit?
